# LabCore

LabCore is a portable, headless diagnostics and embedded computing platform designed around Raspberry Pi, ESP32, and Android.

Instead of treating each device as a separate project, LabCore combines them into a service-oriented ecosystem where every device contributes capabilities such as sensing, GPIO control, networking, vision, audio, and diagnostics.

## Features

- Service-based architecture
- Raspberry Pi service manager
- ESP32 sensor node
- Android (Termux) integration
- Lightweight web dashboard
- REST API communication
- GPIO & UART diagnostics
- Portable field toolkit
- Distributed processing support
- Designed for future AI and computer vision integration

## Project Goals

- Learn embedded Linux
- Build reusable services
- Develop portable diagnostic tools
- Explore distributed edge computing
- Create a modular platform for future projects
